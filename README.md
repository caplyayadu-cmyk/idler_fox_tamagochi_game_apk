# Idler Fox Android releases

This repository contains release instructions and small release metadata only. The Godot source project, player saves, signing keys, and APK binaries do not belong here. APK files are uploaded as GitHub Release assets and are ignored by Git.

## Release files

- `idlerfox.apk` is built in this directory by the main project's Android export preset.
- `latest.json` is generated by `prepare_release.ps1`; upload both files to a **draft GitHub Release** as assets. Do not commit either file.
- The APK URL in the manifest is pinned to the tag being released. The game checks the stable URL `https://github.com/caplyayadu-cmyk/idler_fox_tamagochi_game_apk/releases/latest/download/latest.json`.

## Preparing and publishing

1. Back up the signing key outside both repositories. Keep the same signing certificate as the installed game.
2. Increase `version/code` in the main project's `export_presets.cfg`; set `version/name` and update `CHANGELOG.md` here.
3. From this directory run:

   ```powershell
   .\prepare_release.ps1 -Tag v0.2.0 -GodotExe "C:\path\to\Godot_v4.7.2-stable_win64_console.exe"
   ```

   The script exports the APK, checks package/version/signature metadata, calculates its size and SHA-256, writes `latest.json`, creates a draft release, and attaches both files.
4. Review the GitHub draft and verify release asset URLs, size, checksum, package name and version. Install the APK over a test copy of the previous build and verify that save data and the trade journal remain.
5. Publish only after the update and install flow is checked:

   ```powershell
   .\publish_release.ps1 -Tag v0.2.0
   ```

Use `publish_release.ps1 -Tag vX.Y.Z` only after the draft has been reviewed. Published assets are immutable; make a new tag and release for corrections.

The current repository owner is `caplyayadu-cmyk`. If the owner or repository name changes, update `MANIFEST_URL`, `RELEASES_URL`, and the allowed pinned URL prefix in `scripts/update_manager.gd` as well as this document.
